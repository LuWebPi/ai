# Blobb Ai
VisionTrainer Single-File
Ein einfaches Tool, um KI-Objekterkennung direkt im Browser zu trainieren – alles in einer einzigen HTML-Datei.
# 🚀 Funktionen
Kamera-Training: Objekte direkt per Webcam erfassen.
Fortschritts-Management: Lade deine trainierten KI-Gewichte als Datei herunter und lade sie später wieder hoch, um weiterzutrainieren.
Kein Backend nötig: Läuft komplett lokal in deinem Browser.
# 🛠️ Verwendung
Öffne die index.html in einem modernen Browser (z. B. Chrome).
Erlaube den Zugriff auf deine Kamera.
Erfasse Bilder für deine Klassen (z. B. "Gegenstand A" und "Gegenstand B").
Klicke auf Trainieren.
Nutze Exportieren/Importieren, um dein Modell lokal als Datei zu speichern oder zu laden.
# 💡 Hinweis
Da das Modell im Browser-Speicher liegt, gehen die Daten beim Neuladen der Seite verloren, sofern du sie nicht vorher exportiert hast.
